# Spec Delta

## MODIFIED Requirements

### Requirement: 便携分发包产物
工程 SHALL 产出自带 Java 运行时与启动命令的便携分发包，使目标机器无需预装 Java 即可直接运行应用。分发包自带的运行时 SHALL 仅包含应用实际使用的 JDK 模块（裁剪运行时），而非完整运行时镜像；产物压缩包体积 SHALL 显著小于全量运行时产物。

#### Scenario: 生成便携分发包
- **WHEN** 执行便携分发包打包任务
- **THEN** 产出包含应用 jar、自带运行时目录与启动命令的分发目录

#### Scenario: 无 Java 环境直接运行
- **WHEN** 在未安装 Java 的目标机器上执行分发包内的启动命令
- **THEN** 应用使用分发包自带的运行时正常启动

#### Scenario: 运行时为裁剪的最小运行时
- **WHEN** 执行便携分发包打包任务
- **THEN** 分发包自带的运行时仅包含应用实际使用的 JDK 模块，而非完整运行时镜像

#### Scenario: 产物体积显著缩减
- **WHEN** 在同一平台分别打包裁剪运行时与全量运行时
- **THEN** 裁剪后的压缩包体积显著小于全量运行时压缩包（Windows zip 降至 105MB 以下，且相对基线约 125MB 降幅 ≥ 20%）
